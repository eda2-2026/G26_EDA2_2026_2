# Entrega 1 - Estrutura de Dados e Algoritmos 2 (EDA2)

Este repositório é destinado ao desenvolvimento e envio da **Entrega 1** da disciplina de **Estrutura de Dados e Algoritmos 2 (EDA2)**.

## Sobre a entrega

O objetivo desta entrega é a implementação de algoritmos e estruturas de dados desenvolvidos para a disciplina. Este projeto foi estruturado com base no repositório original [Cafeteria Geek Byte Brew](https://github.com/diangellis/Cafeteria-Geek-Byte-Brew-).

## Conteúdo

- Implementação dos algoritmos propostos para a Entrega 1.
- Documentação e estrutura base herdadas do projeto da Cafeteria Geek.
